# Connected riding gloves

The connected palm/finger anatomy and game-engine skin weights derive from the **CC0 MakeHuman assets in MPFB 2.0.17**. These are the same credited source family as the [rider](../Rider/README.md). The external GPLv3 MPFB authoring program is not copied into the game. [Publisher license distinction](https://github.com/makehumancommunity/mpfb2/tree/v2.0.17) and [MakeHuman output license](https://static.makehumancommunity.org/about/license.html). Upstream asset terms are retained in CC0-1.0.txt. Existing credited Poly Haven brown-leather maps remain in [the premium-material provenance](../../../../../Docs/Art/Reins-Premium-Materials-Provenance.md); no new texture or private reference image is included.

Original authoring work extracts a connected hand at the wrist, corrects the coordinate frame, poses fingers and thumb, softens small skin/nail borders, offsets a thin glove shell, extends a rolled cuff, reduces mesh density and unwraps the surface. The inspection pose has 2,393 triangles; each riding grip has 1,408. The reduction checks source/reduced vertex-to-triangle distances in both directions (sampled surface error, not an exact Hausdorff proof). Maximum sampled error is recorded separately for each pose. This is a fitted leather-shell interpretation, not a sculpted production glove with baked seams, fabric simulation or accepted photorealism.

Run Blender 4.5.13 with `--background --factory-startup --disable-autoexec --python-exit-code 1 --python Tools/Art/export_rider_gloves.py -- <extracted MPFB source> <new output directory>`. The tool stores MPFB session data in that output directory. Copy the two generated JSON surfaces here, preserving Unity metadata, then regenerate Reins through `Tools/run-reins.sh generate`. Source-Provenance.json pins the external source archive and exported mesh files. The source coordinates are metres: X toward the thumb, Y toward the back of the hand, Z toward the fingers. Exported UV seams retain smooth normals; Unity mirrors the right glove with matching index winding. No bone skinning is needed at runtime for these fixed finger poses; existing moving grip transforms and the rider wrist solver carry them.

The first authoring study exposed a palm/back frame reversal; a later thumb-base CCD candidate twisted the web of the thumb. Both were rejected. The final source leaves the thumb base neutral, solves only its distal joints and uses a more open grip to accommodate the braided rein. The supplied warm stable/glove reference remains a quality target, not an asset source. Existing six local glove styles, preview/equip/cancel/save and race appearance isolation remain the feature contract.

## Original sewn construction (September 21)

The two JSON anatomical sources and credited texture bytes remain unchanged. `GloveTailoringBuilder` adds original surface-fitted panels, ribs, thread and a wrist mark at Unity authoring time; the persistent finished meshes are used in actual race/inspection views. `TailoredLeather.shader` uses RGB for local leather shading and alpha for fixed thread, never transparency. Read [the construction checkpoint](../../../../../Docs/Art/Reins-Glove-Tailoring-Checkpoint.md) for current geometry costs and verification. Existing sources retain their original CC0 provenance; no reference pixels, logos or new downloaded assets are used.
