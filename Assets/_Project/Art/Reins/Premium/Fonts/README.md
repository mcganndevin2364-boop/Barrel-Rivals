# Reins HUD typefaces

Unmodified TrueType fonts served by Google Fonts. Cinzel SemiBold is the western-inspired display face; Lato Regular/Bold are used for legible controls and timing. Both are free to bundle and embed under SIL Open Font License 1.1. Full copyright and license texts accompany these files. No font is sold separately or represented as original Barrel Rivals work.

See font-sources.json for versioned source URLs and SHA-256 hashes. Cinzel copyright: The Cinzel Project Authors. Lato copyright: tyPoland Lukasz Dziedzic, reserved font name Lato. Retain both license files when redistributing.

Copies of both complete licenses are also under Resources, so Unity includes their copyright/license notices in player builds alongside the fonts.
