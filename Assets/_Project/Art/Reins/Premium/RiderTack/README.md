# Original rider tack — foreground integration study

These meshes are generated reproducibly by `ReinsRiderTackBuilder.Build(horse)` from original curve/loft definitions. No paid asset, reference-image pixels, sponsor artwork, or external model is embedded here. Gloves and headstall use the licensed leather photographic base color, normal and roughness sources recorded in the premium arena material provenance; URP materials and channel packing are shared through `ReinsPremiumArenaBuilder.Pbr`. Steel, braid, thread and sleeve use original URP Lit color/roughness definitions. This directory is builder-owned: mesh regeneration updates the existing assets in place and preserves their GUIDs; existing material authoring is retained.

The closed-grip gloves have a shaped palm, four separately curled fingers, opposed thumb, cuff, forearm sleeve, reinforcement and thread details. The bridle is authored around the current normalized CC0 horse and attached to its imported `Bone.002` head transform. Steel bit rings anchor two turquoise/flax-accented braided reins. Two custom deformable meshes contain 594 vertices and 1,152 triangles each, with three material slots per rein; they are copied privately at runtime rather than modifying persisted shared assets.

`ReinsRiderTackPresentation` reads the accepted horse presentation's rein tension, speed and turn only. The hand pose and rein curve follow these values without physics, authority, controller input polling, gameplay state changes, or per-frame managed-array creation. Run it after Animator updates and use `RenderImmediate()` for paused captures. Head attachment uses the saved bind transform; reins end at the animated bit anchors. Reset/cancel clears the source tension and restores neutral grips on the next presentation update.

This is a first-person foreground integration study, **not a finished rigged rider or accepted premium-realism asset**. It has no elbow/shoulder skeleton, full body, skin shader, tack skinning, saddle simulation, IK, contact/foot-plant solution, or physically simulated rein dynamics. Hand/bridle fit, silhouette, clipping in every gait and full-course motion still require actual engine and device review. No device performance claim follows from the geometric counts above. The source generator is the editable art definition; improve that definition or replace it with a properly authored rigged production asset before declaring the rider milestone complete.
