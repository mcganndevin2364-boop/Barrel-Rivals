# Reins 0.5 — phone review

This review applies only after version 0.5.0/build 5 has been installed and verified. Previous 0.4 feedback remains historical. The new game includes Reins-only startup, the moving alley, a seated rider, revised hands/reins, warm stable, equipment previews and local equip/save behavior.

## Quick player review

1. Hold the center control. The horse should walk down the alley for four seconds; three beeps happen at seconds 2, 3 and 4. Release near the last beep. The invisible score line should feel predictable from the approaching arena. Early or late releases should still allow the run to continue.
2. Steer with the side reins, tap the center to the heartbeat, and hold center near a barrel to Wrap. Finish all three turns and the drive home. Check thumb reach and whether the horse, hands or HUD obscure the next barrel.
3. Retry, try a held start and an early release, then interrupt the app and return. A canceled attempt must not retain held input or scheduled beeps. Try sound off and reduced motion.
4. Open My Stable before a run. Rotate the horse, preview tack and each glove style, cancel one preview, then equip another. Ride back into the arena and check the chosen appearance. Close and reopen the app to check local persistence.
5. Note any clipping, jerky transitions, pink materials, flickering, hard-to-read labels or excessive heat. Record the exact scene and action; a screenshot or short phone recording helps locate it.

## Developer qualification still required

A successful compile, signature or install does not establish visual or runtime quality. Measure a 20-minute repeat-race session, including scene changes and ghost playback, on the named phone. Record frame-time percentiles, memory, thermals, battery conditions, resolution/quality settings and touch/audio alignment. Targets remain 60 FPS/p95 <=16.7 ms, with a separately qualified 30 FPS/p95 <=33.3 ms fallback. The existing source exceeds its character triangle/material targets; this build does not waive those requirements.

No Android handset, multiplayer authority, ownership/rewards, cloud save or store release acceptance is implied by this review.
